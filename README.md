# Laravel Task API

Minimal Laravel 13 + SQLite task API. Routes: `GET/POST /api/tasks`, `PATCH/DELETE /api/tasks/{id}`.

Run `composer install`, `php artisan migrate`, `php artisan serve`; test with `php artisan test`. Seed examples with `php artisan db:seed --class=DemoTaskSeeder`.

Backdated sample commits in this repository are synthetic.
